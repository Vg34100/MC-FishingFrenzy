# Release notes

## 1.2.3

- Adds Minecraft 1.20.1 support on Fabric and Forge, and Minecraft 26.3 support on Fabric and NeoForge.
- Adds the eight missing fish-to-bait recipes. All 15 fish now craft into two matching baits.
- Fixes fish spawning from eggs on Minecraft 1.20.1 and bait that could prevent bites on that version.
- Fixes baby fish growing up, breeding cooldowns, feeding growth, and breeding checks.
- Fixes bait use when a catch produces several items, keeps stored bait details, and counts the fish actually caught.
- Makes natural spawning follow the world's day and night cycle after sleeping or changing the time.
- Supports clients and dedicated servers. Requires Architectury API, plus Fabric API on Fabric. Mod Menu remains optional.
- On Minecraft 26.2 Fabric, use Fabric Loader 0.19.5 or later with current Architectury API and Fabric API.

## 1.2.2

- Fishing Frenzy is available for Minecraft 1.21, 1.21.1, 26.1, 26.1.1, 26.1.2, and 26.2 on Fabric and NeoForge.
- Supports clients and dedicated servers. Install Architectury API on both loaders and Fabric API on Fabric; Mod Menu is optional on Fabric.
- For Minecraft 26.2 on Fabric, use Fabric Loader 0.19.5 or later with current Architectury API and Fabric API.
